# Ориентиры: мировые проекты национального/городского масштаба

> Исследование от 2026-10-10. Что брать и чего не брать у аналогов, перечисленных в разделе 2 AGENTS.md.

## UK National Digital Twin Programme (NDTP)

- Госпрограмма Великобритании, с 2018. До сентября 2022 — Centre for Digital Built Britain (Кембридж), затем прямое госуправление (Department for Business and Trade). Горизонт — до 2035.
- Ключевая идея: **не один гигантский двойник, а федерация** независимых двойников, обменивающихся данными по общим правилам.
- Составляющие:
  - **Gemini Principles** — ценности: общественная польза, открытость, безопасность, качество данных.
  - **Information Management Framework (IMF)** — «7 кругов»: Core Constructional Ontology → 4D Top-Level Ontology → Foundation Data Model → Reference Data Library → Integration Architecture и выше.
  - **Integration Architecture (IA)** — open source узлы (IA Node), Federator и Management Node; объединяются в Node Net → National Node Net.
- Состояние на 2026:
  - IA активно развивается: Federator v1.0, Management Node v1.1 — production-ready, деплой на AWS/Azure/GCP, каталог данных. Документация — ndtp.co.uk.
  - Онтологический слой (FDM/RDL) как отдельные артефакты фактически заморожен в виде документов на Digital Twin Hub.
  - Его роль на практике заняла **IES (Information Exchange Standard)** — 4D-онтология британского правительства, с марта 2025 развивается в репозитории IES-Org/ont-ies межведомственной рабочей группой.
- **Что брать:** архитектуру федерации узлов (edge → региональный → центральный), Gemini Principles, приоритет мастер-данных.
- **Чего не брать:** «7 кругов» буквально — этот путь они сами де-факто сократили.

## Virtual Singapore

- 3D-двойник города-государства, 2014–2022, ~S$73 млн, платформа Dassault 3DEXPERIENCity, лидарная съёмка с воздуха и машин. NRF + Singapore Land Authority + GovTech.
- Демонстрирует уровень детализации «вся страна в одной модели».
- Итог: публичная фаза не запустилась, независимых оценок эффекта нет, название исчезло с госстраниц. Когда Сингапуру понадобились **работающие** двойники (район Punggol с датчиками, Maritime Digital Twin порта, 2025), их построили как отдельные системы. Картографическая основа живёт как OneMap3D.
- **Урок:** 3D-картинка ≠ операционный двойник. Ценность — в живых данных и управлении, а не в визуализации.

## Asset Administration Shell (AAS)

- Стандарт Industrie 4.0 (IDTA, IEC 63278): стандартизированная «цифровая оболочка» любого актива — от датчика до завода.
- Актив = AAS + набор типизированных **подмоделей** (Nameplate, TechnicalData, Documentation и т.д.) с семантическими ID (ECLASS / IEC CDD).
- REST API, сериализация JSON / XML / AASX. Подмодели компонуются; на этом в 2026 строится EU Digital Product Passport (EN 18222/18223, IDTA-02099).
- **Что брать:** формат описания устройства / шкафа / клеммы на нижних уровнях иерархии активов.
